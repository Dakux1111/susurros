# Susurros 🌿

Un jardín para las ideas que llegan sin avisar — cultiva lo que sientes antes de que se te escape.

Aplicación web de una sola página (HTML) para registrar ideas espontáneas junto con la emoción y categoría con las que llegaron. Cada idea crece como una planta según su estado: 🌱 semilla → 🌿 en cultivo → 🌸 floreció.

## Características
- Registro rápido de ideas con emoción y categoría
- Vista de jardín (visual) y vista de lista
- "Regar" para marcar que sigues pensando en una idea sin cambiar su estado
- Ideas que se marchitan visualmente tras 10 días sin agua
- Filtros por categoría
- Todo se guarda en el navegador (localStorage) — sin servidor, sin login
